# 기획서: 벽돌깨기

## 만들 것

빨간 벽돌을 공으로 맞혀 모두 없애는 1인용 웹 게임을 만든다. 플레이어는 검은색 막대를 좌우로 움직여 공을 받아낸다.

## 화면과 크기

| 항목 | 사양 |
| --- | --- |
| 기준 모니터 | 1024 × 768px |
| 게임판 | 기준 크기 1024 × 640px, 흰색 배경 |
| 벽돌 | 빨간색, 가로 100px × 세로 24px |
| 벽돌 배치 | 7행 × 9열, 가로·세로 간격 8px. 게임판 위쪽 가운데에 배치 |
| 조작 막대 | 검은색, 가로 150px × 세로 16px. 게임판 아래쪽에서 좌우로 이동 |
| 공 | 짙은 회색, 지름 14px |
| 상태 표시 | 게임판 위에 점수와 남은 기회를 보여 준다. 게임판에는 현재 상태에 맞는 시작·재시도 안내를 표시한다. |

게임판의 기준 크기는 게임 안에서 위치와 크기를 계산할 때 사용한다. 브라우저 주소창 때문에 실제로 보이는 공간이 좁을 수 있으므로, 화면이 작으면 게임판 전체를 같은 비율로 줄인다. 1024 × 768 모니터의 최대화된 브라우저에서 게임판과 상태 표시가 한 화면에 보이도록 한다.

## 조작과 진행

1. **시작 대기** — 처음에는 공이 막대 위에 멈춰 있다. 스페이스 키를 누르면 공이 위쪽으로 출발한다.
2. **막대 이동** — 왼쪽·오른쪽 방향키로 막대를 이동한다. 막대는 게임판 밖으로 나갈 수 없다.
3. **충돌** — 공은 위쪽과 양쪽 벽, 막대, 벽돌에 맞으면 튕긴다. 벽돌은 한 번 맞으면 사라지고 점수 10점을 얻는다.
4. **공을 놓쳤을 때** — 남은 기회가 하나 줄어든다. 기회가 남았다면 막대와 공을 가운데로 돌려놓고, 스페이스 키를 눌러 같은 판을 이어 간다. 이미 없앤 벽돌과 점수는 유지한다.
5. **승리와 패배** — 벽돌을 모두 없애면 승리한다. 처음 주어진 기회 3개를 모두 잃으면 패배한다. 승리 또는 패배 화면에서 스페이스 키를 누르면 벽돌, 점수, 기회를 초기화하고 시작 대기 화면으로 돌아간다.
6. **키 입력 처리** — 게임 화면에서 방향키와 스페이스 키를 눌러도 브라우저 페이지가 스크롤되지 않게 한다. 게임 진행 중 스페이스 키를 눌러도 새 판이 시작되지 않는다.

## 파일 구성과 실행

| 경로 | 역할 |
| --- | --- |
| `brick_game.html` | 게임판, 점수, 남은 기회, 조작 안내를 배치한다. |
| `brick_game.css` | 색상, 글자, 화면 크기에 따른 배치를 지정한다. |
| `brick_game.js` | 키 입력, 공과 막대 이동, 충돌, 점수, 승패를 처리한다. |

세 파일은 이 실습 폴더에 둔다. `brick_game.html`을 더블클릭해 실행한다. 게임 로직에는 일반 JavaScript를 사용하고, 서버나 외부 라이브러리 없이 실행되도록 만든다.

## 완료 기준

- [ ] `brick_game.html`을 더블클릭하면 브라우저에서 게임이 열린다.
- [ ] 1024 × 768 기준 화면에서 게임판과 상태 표시가 보인다. 시작 화면에서 흰 배경, 빨간 벽돌 7행 × 9열, 검은 막대를 확인한다.
- [ ] 시작 전에는 공이 멈춰 있다가 스페이스 키를 누르면 출발한다. 방향키로 막대가 움직이고 게임판 경계를 넘지 않는다.
- [ ] 공이 벽돌을 맞힐 때 벽돌 하나가 사라지고 점수가 10점 오른다. 벽돌 63개를 모두 없애면 630점으로 승리한다.
- [ ] 공을 놓칠 때마다 기회가 하나 줄고, 기회가 남아 있으면 기존 점수와 벽돌 상태로 이어 할 수 있다. 마지막 기회를 잃으면 패배한다.
- [ ] 승리 또는 패배 후 스페이스 키를 누르면 벽돌이 복구되고 0점, 기회 3개의 시작 대기 화면으로 돌아간다.

## 구현 전에 검토할 질문

아래 질문에 별도 수정이 없으면 위 사양을 적용한다.

- 벽돌의 100px과 막대의 150px은 가로 길이로 보면 될까? 세로 길이는 각각 24px와 16px로 배치했다.
- 막대는 좌우 방향키로만 조작하면 될까? 마우스나 터치로도 조작해야 하는지 정할 수 있다.
- 기회 3개와 벽돌당 10점이 수업 실습에 적당할까?
- 공 속도는 한 판 동안 일정하게 유지할까, 벽돌을 깰수록 더 빠르게 할까? 이 사양에서는 일정한 속도를 기본값으로 둔다.
