# 기획서: 자기소개 웹페이지

## 누가 쓰나

수업에서 처음 만난 친구들

## 만들 것

가상의 대학생이 자신을 소개하는 한 페이지짜리 웹페이지

## 기능

1. 별명과 한 줄 소개 (별명은 요청할 때 알려 줌. 현재 예시는 구름빵)
2. 좋아하는 것 3가지와 각각의 짧은 설명
3. 버튼을 누르면 배경색이 바뀜

## 디자인과 화면 구성

- **주제** — 구름빵이 산책길에 발견한 하늘
- **첫 화면** — 연한 하늘색을 바탕으로 별명을 가장 크게 표시하고, 아래에 한 줄 소개를 넣는다. 여백에 CSS로 구름 모양을 그린다.
- **좋아하는 것 3가지** — 항목마다 제목과 짧은 이야기를 붙인다.
  - **음악 들으며 산책하기** — 수업이 끝나면 좋아하는 노래를 들으며 한 바퀴 걸어요.
  - **하늘 사진 찍기** — 해 질 무렵 구름이 분홍빛으로 바뀌는 순간을 좋아해요.
  - **프렌치토스트 만들기** — 주말 아침에 빵 가장자리를 바삭하게 굽는 게 좋아요.
- **배경색 버튼** — 버튼에 ‘하늘색 바꾸기’라고 적는다. 처음에는 아침 하늘색을 보여 주고, 누를 때마다 연한 노을빛 주황색, 짙은 밤하늘색, 아침 하늘색 순서로 바뀐다. 모든 배경에서 소개 글과 버튼을 읽기 쉽게 유지한다.
- **마무리 문구** — “학교 근처에 맛있는 빵집을 아시면 알려 주세요!”처럼 친구가 답하기 쉬운 말로 끝맺는다.
- **휴대전화 화면** — 화면이 좁으면 좋아하는 것 세 가지를 한 줄에 하나씩 세로로 배치한다.

## 조건

- index.html 파일 하나에 HTML, CSS, JavaScript만 사용
- 외부 라이브러리, 서버, 데이터베이스는 사용하지 않음
- 실명, 연락처, 사진은 넣지 않음

## 완료 기준

- 01-intro/index.html을 더블클릭하면 브라우저에서 바로 열린다.
- 첫 화면에 별명과 한 줄 소개가 보이고, 좋아하는 것 세 가지에 각각 설명이 붙어 있다.
- 버튼을 세 번 눌러 배경색이 노을빛 주황색, 짙은 밤하늘색, 아침 하늘색 순서로 바뀌는지 확인한다. 색이 바뀔 때마다 소개 글과 버튼을 읽을 수 있다.
- 브라우저 창을 휴대전화 너비로 좁히면 좋아하는 것 세 가지가 세로로 배치되고, 글이 잘리거나 가로로 넘치지 않으며 버튼을 누를 수 있다.
